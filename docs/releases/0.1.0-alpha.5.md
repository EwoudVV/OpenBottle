# OpenBottle 0.1.0 alpha 5

this build preserves per-game environment settings across a cold Steam launch.

the previous two-step path started a generic Steam client first and sent
`-applaunch` afterward. the running client launched the game with its original
environment, so the game got the DXMT DLLs but could miss profile-only settings
such as MetalFX spatial upscaling and the 120 FPS cap.

on a cold launch, OpenBottle now sends the profiled `-applaunch` first and
waits for that same Steam process and game. this matches the launch model proven
by the Screw Drivers script while retaining the shared save and rollback
transaction.

OpenBottle 0.1.0 build 5 remains ad-hoc signed and not notarized.
