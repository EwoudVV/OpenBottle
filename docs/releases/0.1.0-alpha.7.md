# OpenBottle 0.1.0 alpha 7

this is the first build tested end to end with the copied Screw Drivers bottle.

- the 55 GB bottle import stays below 400 MB of memory;
- save snapshots are accepted and verified before Steam starts;
- cold Steam launches keep the game's DXMT, MetalFX, and frame-cap settings;
- a cold Steam start can take up to 150 seconds instead of failing at 90;
- imported pins and blocked-program paths point into the OpenBottle copy, so
  they do not depend on the old Whisky bottle.

OpenBottle 0.1.0 build 7 remains ad-hoc signed and not notarized.
